# Data Model: ArgoCD Install Infra Apps

**Date**: 2026-08-19 | **Feature**: 008-argocd-install-infra

## Entities

### GitHub Repository Credential (Kubernetes Secret)

| Field | Type | Description |
|-------|------|-------------|
| `metadata.name` | string | `github-repo-cred` |
| `metadata.namespace` | string | `argocd` |
| `metadata.labels` | map | `argocd.argoproj.io/secret-type: repository` |
| `type` | string | `kubernetes.io/basic-auth` |
| `data.username` | base64 | GitHub username |
| `data.password` | base64 | GitHub personal access token |

### ApplicationSet `cluster-apps`

| Field | Type | Description |
|-------|------|-------------|
| `metadata.name` | string | `cluster-apps` |
| `metadata.namespace` | string | `argocd` |
| `spec.generators[0].git.repoURL` | string | `https://github.com/natanbs/argocd-infra.git` |
| `spec.generators[0].git.revision` | string | `HEAD` (or `ARGOCD_INFRA_BRANCH` value) |
| `spec.generators[0].git.files[0].path` | string | `apps/*.yaml` |
| `spec.template.spec.syncPolicy.automated.prune` | bool | `true` |
| `spec.template.spec.syncPolicy.automated.selfHeal` | bool | `true` |
| `spec.template.spec.syncPolicy.syncOptions` | list | `["CreateNamespace=true", "ServerSideApply=true"]` |

### App Registration (YAML in `apps/`)

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Application name (e.g., `vault`) |
| `repoURL` | string | GitHub repo URL for the app |
| `appPath` | string | Path within the repo (usually `.`) |
| `namespace` | string | Target Kubernetes namespace |

### ArgoCD Application (generated by ApplicationSet)

| Field | Type | Description |
|-------|------|-------------|
| `metadata.name` | string | From `name` field in registration YAML |
| `metadata.namespace` | string | `argocd` |
| `spec.source.repoURL` | string | From `repoURL` field |
| `spec.source.targetRevision` | string | `HEAD` |
| `spec.source.path` | string | From `appPath` field |
| `spec.destination.server` | string | `https://kubernetes.default.svc` |
| `spec.destination.namespace` | string | From `namespace` field |
| `spec.syncPolicy.automated` | object | `prune: true, selfHeal: true` |

## Relationships

```
GitHub Repository Credential (Secret)
    └── referenced by ArgoCD for repo authentication
         └── ApplicationSet reads apps/*.yaml from repo
              └── generates one Application per YAML file
                   └── each Application deploys to target namespace
```

## State Transitions

### Secret

```
Not exists → Created (kubectl apply)
Created → Updated (kubectl apply on re-run, idempotent)
```

### ApplicationSet

```
Not exists → Applied (kubectl apply)
Applied → Updated (kubectl apply on re-run, idempotent)
```

### Application (per app)

```
Not exists → Created by ApplicationSet
Created → Syncing → Synced (healthy)
Synced → OutOfSync (when source changes)
OutOfSync → Syncing → Synced (auto-sync with selfHeal)
```

## Validation Rules

- Secret MUST have label `argocd.argoproj.io/secret-type: repository`
- Secret MUST be of type `kubernetes.io/basic-auth`
- ApplicationSet MUST target `argocd` namespace
- Each App Registration YAML MUST have `name`, `repoURL`, `appPath`, `namespace` fields
